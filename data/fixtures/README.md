# Fixtures

Saved upstream responses used by tests and by the offline/replay demo. Tests never touch the network.

**Provenance.** ESPN and Kalshi were blocked from the build sandbox, so the ESPN and Kalshi files here
were generated by `scripts/build_fixtures.py` from real nflverse data and carry `"_synthetic": true`
plus a `_source` note. Plays, players, scores and win probabilities are real (nflverse); only the JSON
layout is ESPN's. Run `pnpm fixtures:fetch` on a networked machine to overwrite them with real
responses before demo day.

| File | Contents |
| --- | --- |
| `espn/summary_401873002.json` | Demo game PIT 26 @ TB 19 (OT), 2026 week 6: drives, plays, win probability, pickcenter |
| `espn/scoreboard_2026_wk6.json` | Week 6 scoreboard (all final, includes the demo game) |
| `espn/scoreboard_2026_wk7.json` | Week 7 scoreboard, includes PIT vs NO in Paris (`401873011`) |
| `espn/team_{PIT,NO,TB}.json` | Team info |
| `espn/roster_{PIT,NO,TB}.json` | Rosters (nflverse weekly roster, real ESPN athlete ids) |
| `espn/depthchart_{PIT,NO,TB}.json` | Depth charts by formation group (nflverse depth charts are ESPN-sourced) |
| `kalshi/events_KXNFLGAME.json` | Kalshi `/events` snapshot for week 7. **Prices are de-vigged sportsbook closing lines, not Kalshi trades.** Shape only |
| `nflverse/pbp_2026_06_PIT_TB.csv` | Demo game play-by-play, all nflverse columns |
| `nflverse/parser_eval_{2024,2025,2026}.csv.gz` | Labeled plays from 3 seasons for the parser accuracy harness |

Rebuild: `python scripts/fetch_nflverse.py && python scripts/build_fixtures.py` (needs pandas).
